# Ars-Technia — versão Web Desktop

Projeto convertido para **React + JavaScript (JSX) + CSS**, com navegação entre as telas desktop e componentes compartilhados para manter Header, Sidebar e rodapé consistentes.

## Como executar

1. Instale o Node.js (versão 18 ou superior).
2. Abra o terminal na pasta do projeto.
3. Execute `npm install`.
4. Execute `npm run dev`.
5. Abra o endereço local exibido pelo Vite (normalmente `http://localhost:5173`).

## Build de produção

Execute `npm run build`. Os arquivos finais serão gerados na pasta `dist/`.

## Navegação

- O menu lateral acessa as áreas principais.
- O nome do usuário no cabeçalho alterna entre Professor e Gestão.
- As notificações abrem as solicitações do perfil atual.
- Os botões de detalhes, cadastro, edição e sair possuem navegação/ações locais demonstrativas.

Esta entrega contém somente os layouts desktop. As versões mobile não foram desenvolvidas nesta etapa.
