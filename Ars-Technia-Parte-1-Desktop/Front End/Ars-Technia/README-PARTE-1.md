# Ars-Technia — Parte 1 (Desktop)

Esta etapa contém somente as seis telas solicitadas:

1. Agendamento
2. Cadastro de Conta
3. Cadastro de Salas
4. Detalhes do Local
5. Editar Perfil
6. Login

O projeto é um **site React com JavaScript/JSX e CSS**, executado pelo Vite. Não usa React Native nem Expo. A estrutura está organizada em `src/screens`, `src/components`, `src/context` e `src/styles`.

## Executar

1. Abra a pasta `Ars-Technia` no VS Code.
2. No terminal, execute `npm install`.
3. Depois execute `npm run dev`.
4. Abra o endereço local indicado pelo Vite.

As telas restantes serão incluídas na Parte 2 e na etapa final. Por isso, alguns destinos que pertencem às próximas etapas ainda exibem a página inicial temporária desta primeira parte.
